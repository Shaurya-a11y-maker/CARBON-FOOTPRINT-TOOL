# Multi-Year Carbon Footprint Comparison Tool

A browser-based tool to upload monthly power consumption data by state and year, calculate carbon footprint using emission factors, visualize multi-year trends in an interactive chart, and export a PDF summary report. Built with HTML, Bootstrap, and Chart.js — no backend required.

## Features
- Upload monthly power data (CSV) per year and state
- Automatic carbon footprint calculation using emission factors
- Multi-year comparison chart (power consumption vs. carbon footprint)
- Downloadable PDF summary report
- Built entirely with client-side JavaScript, no backend required

## Tech Stack
- HTML5, Bootstrap 5
- Chart.js (data visualization)
- jsPDF + html2canvas (PDF export)
